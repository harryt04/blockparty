## Scaffold status

Every ENG-003 page and Route Handler exists and returns a shaped placeholder;
that verifies no product requirement. Ticket 0.1 added the root gate and one
real test per project. Ticket 0.2 added the PR workflow and active `master`
ruleset. Remaining fake builders stay centralized in
`apps/web/src/server/stub-data.ts` and are removed by Loop B.

There is no service worker until F1 proves an app-shell-only cache, and no font
files until licensed, provenanced self-hosted faces exist.

## Completion rule

Code alone never makes a requirement `Verified`. Link implementation, required
automated/manual evidence, applicable migration/operations evidence, and every
release-gate approval first.
